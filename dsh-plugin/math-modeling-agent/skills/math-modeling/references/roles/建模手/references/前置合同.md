# 模型合同

模型合同不是分析前的猜测，也不是独立交付物。它应在完整读题和检查附件后形成，并写入 `题目分析报告.md`。

## 内容

| 项目 | 必须回答的问题 |
|---|---|
| 任务定义 | 每个子问题要求计算、预测、评价或决策什么？ |
| 数据 | 输入字段、单位、范围、质量和只读文件是什么？ |
| 结论类型 | 理解题目后，最终需要给出哪类结论和指标？ |
| 模型 | 每个子问题选哪一个或两个模型？为何适配？ |
| 数学定义 | 变量、参数、目标函数、约束、假设和边界条件是什么？ |
| 实现 | 输入输出、算法步骤、停止条件和依赖是什么？ |
| 验证 | 用什么真实数据、误差、稳定性或对照检验结果？ |
| 风险 | 哪些条件不满足时必须回退或更换方案？ |

数据判定标准必须注明题目、官方规则、文献或数据分析依据。

## 关键逻辑检查

按实际主张触发以下检查，将必要证据写在合同对应位置，不新增固定交付物或强制大表。只检查会影响结论的环节；不适用项跳过，不为填表增加模型、实验或外部资料。尊重用户限定的信息来源。

- **数学对象与成立条件**：用公式、替代量或近似代表题目目标时，先明确目标对象，再说明映射及等价或近似成立的条件。区分定义、假设、充分条件与必要条件；对决定结论的转换，用简短推导、解析特例或反例检查其依据，不要求逐式证明。涉及优化时，核对目标方向、约束及适用的边界情形，确认改善目标确实对应题目希望的行为。
- **比较与归因**：声称模型改进或某因素有效时，列明基准与候选之间改变的变量变换、样本、模型结构、调参方式和评价口径等适用因素。在共同评价尺度和范围上比较；若同时改变多项，用控制其他因素的对照或适当的消融支持贡献归因。只有整体方案的比较证据时，只声称整体差异，不归因于单项改动。跨子问题存在这类比较时同样适用；并不要求独立任务使用相同模型。分析阶段写清比较设计，不虚构性能。
- **从模型到决策**：题目要求判定、推荐、调度或预警等行动时，明确输入在决策时是否可得、从预测或求解结果到行动的规则，以及影响该任务的缺失、边界、并列或不可行情形如何处理。用代表性实例或符号实例走通输入到最终输出，并检查适用的关键分支。分析阶段可保留尚未估计的参数，但必须定义阈值、权重或规则如何确定和使用；仅写“训练分类器”“设置阈值”或“必要时复核”不能代替决定结果的步骤。示例只验证逻辑，不作为真实效果证据。

已发现的逻辑错误、无依据的等价关系、不能支持所声称归因的比较或影响最终输出的规则缺口，应在建模阶段修正或相应收缩主张。只有依赖未执行实验的数值问题才进入后续验证计划，并注明检验方法、失败条件和处置；不得用“后续验证”掩盖当前已知错误。

## 参数依据（按需补充）

反演、参数估计或标定任务，在上述数学定义、验证和风险中补充以下内容，不另建交付物；简单任务可用简短说明，不强制大表。

| 项目 | 必须回答的问题 |
|---|---|
| 参数角色 | 哪些是目标、辅助、固定或派生参数？函数型参数有多少自由度，哪些跨数据组共享？ |
| 观测依据 | 每个待估参数或参数组合由什么观测特征约束？哪些依据来自数据，哪些来自固定假设、先验或外部标定？ |
| 补偿风险 | 是否存在缩放、平移、相位、增益等参数补偿？现有公式能排除什么，哪些问题需在 P1 检验？ |
| 验证计划 | 如何检验目标参数恢复、稳定性与预测误差？候选复杂度、数据划分、容差及其依据是什么？ |
| 结论边界 | 信息不足时报告参数组合、区间还是条件性结果？何时返回建模手，何时需要新增数据或用户选择？ |

执行边界与阶段验收以 [可辨识性与复杂度控制](../../../可辨识性与复杂度控制.md) 为准；不得用“联合拟合得到”代替观测依据。
