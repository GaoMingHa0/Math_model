# 可辨识性与复杂度控制

## 适用范围

反演、参数估计或标定任务读取参数依据与对应阶段条款；预测、回归等需要选择复杂度的任务读取复杂度与验证条款。简单的描述、确定性计算或无参数反演的优化任务，不强制套用整套测试。只做分析时提出验证方案，不要求提前完成编程。

本文件规定判断依据，不指定通用参数上限、固定交叉验证折数、条件数阈值或某道题的波段/常数。检查规模按目标误差、数据结构和风险确定；阈值须有依据。尊重用户限定的数据与文献范围，不能为通过检查擅自引入外部标定或固定值。

## 模型合同：参数靠什么确定

将以下信息写入既有模型合同，不新增交付物：

- 区分目标、辅助、固定和派生参数；函数型参数说明基函数/自由度、跨组共享方式和物理作用。
- 说明各待估参数或组合受什么观测特征约束，区分数据提供的信息与固定假设、先验、正则化或外部标定提供的信息。
- 检查相位、增益、基线、尺度等辅助自由度是否能补偿目标参数；多个数据组的数量不等于独立约束数量。
- 指定可接受的结论类型、目标误差依据、候选复杂度、验证数据使用方式及失败回退；无法分离参数时允许报告组合、区间或条件性结果，并说明原问题尚未解决的部分。

## M1：先做静态检查

1. 检查公式、约束、单位及观测映射是否完整。对疑似耦合参数，尝试缩放、平移或其他保持预测不变的变换，或给出适用的解析辨识依据；不强求每个任务证明全局唯一性。
2. 区分结构不可辨识（理想观测下仍有等价参数）、实际弱辨识（现有采样和噪声难以区分）与数值病态（尺度、精度或算法问题）。静态检查不能确定的部分列为 P1 待检验项，规定失败后如何收缩结论或返修。
3. 明确的参数补偿未解决时，不批准无条件的唯一参数结论；可改为识别参数组合、注明条件的估计或补充信息方案。正则化、窄边界和固定参数只能改变所加条件，不能证明原数据具有辨识能力。

例如在 y=a*b*x 中，不同的 a、b 可保持 a*b 不变；拟合精确或增加同类 x 样本都不必然分离 a 与 b。具体任务应检查自己的观测映射，而非机械套用此例。

## P1：最小实现必须检验什么

- 对合同声明可估计的关键目标，使用结构等价、已知真值的无噪声小实例或解析特例验证恢复与单位；合成实例应保留会影响辨识的采样方式、共享关系与辅助自由度，不得通过悄悄固定未知量简化掉风险。
- 有耦合、非凸或弱辨识风险时，再用少量不同初值、参数点或扰动作针对性检查，同时比较拟合损失和目标参数。若相近预测对应明显不同参数，应诊断而非只保留最优一次。
- 对已识别的不可辨识情形，检查实现能否报告参数组合或不唯一，不能要求它恢复不存在的唯一真值。Jacobian 的秩、奇异值或条件数须考虑尺度；它们是局部诊断，不能单独证明全局唯一性。
- 容差由精度目标、尺度和求解误差决定。小实例通过只支持实现与该实例的恢复能力，不证明真实数据、全部参数域或物理假设正确。最小测试失败时先定位原因，停止后续高成本扩展。

P1 只做必要的小实例、少量初值和扰动；全量扫描、完整敏感性分析和正式出图仍在通过后执行。

## 复杂度升级与验证数据

1. 先建立满足物理约束和任务目标的简单基准。每次增加一类可解释的机制或自由度，说明其对应的观测/残差问题；同时改变多项时应能分辨改进来源。具体按 [模型合同的比较与归因要求](roles/建模手/references/前置合同.md#关键逻辑检查) 列明变动并设计对照；跨子问题的改进归因也须满足，只有整体比较证据时不归因于单一因素。
2. 在使用最终验证数据前确定候选复杂度、主要指标和划分方案。相关数据按独立单位、时间顺序或连续区块划分；间隔/区块尺度按相关结构确定，不能把密集相关观测当成同等数量的独立样本。
3. 从数据学习的归一化、去趋势、特征选择、波段/窗口选择与超参数调节纳入训练/内部验证；不得借验证点的信号或跨边界平滑泄漏信息。预先确定、与验证数据无关的物理转换可以统一使用。记录每一步使用的数据范围。
4. 数据充足时保留未参与选择的最终检验；数据不足则采用适用的嵌套、分块或外部验证并说明限制，不强求每题同时使用全部方法。反复根据最终验证表现改方案后，该数据不再是独立最终检验。
5. 升级依据包括预定验证改善、物理合理性与目标参数表现。预测改善不能单独证明参数更可信；若目标参数随复杂度明显变化，应解释偏差修正或辨识退化的证据，未解释时报告模型依赖、保留更简单方案或收缩结论，不自动判定新模型更准。

## P2：区分预测可靠与参数可靠

按实际风险选择诊断，不把下列方法全部强制执行：

- 核对训练与验证损失、残差结构和复杂度比较，使用一致的评价范围；不能通过为不同模型挑选有利样本来比较优劣。
- 检查目标参数对初值、允许的数据子集、辅助自由度、边界以及先验/正则化强度的敏感性；报告近似最优解的差异。若结果主要由先验或边界决定，应明确标为条件性结论。
- 区分预测区间、给定模型/固定参数的条件性参数区间，以及模型选择、标定和假设的不确定性。剖面损失或重采样按所声称的范围重估辅助参数；若固定了部分量，应说明条件，不把条件区间当总误差。
- 多方法或多组结果一致时说明是否复用了数据、相位提取、先验或标定；内部一致性不能写成独立验证。用同一模型生成和拟合的模拟不能作为独立物理证据。
- 仅在相应风险出现时核验统计方法的前提：相关噪声的重采样应保留依赖结构；参数处于边界或零假设下有未定义参数时，不能直接套用常规区间/检验，可采用有依据的零假设模拟并重拟合；信息准则须说明似然及自由度口径，不能把任意惩罚损失和原始点数直接代入标准公式。

如证据只支持参数组合、宽区间或“现有数据不足以唯一确定”，据实交付并标明原任务的未决部分；不通过增加小数位、重复优化或人为收紧边界制造确定性。

## 返修边界

- 编程手可直接修复单位/索引实现错误，采用等价的尺度变换与稳定求解器，改善效率，并执行合同允许的初值搜索、调参和验证；保留原模型的数学含义与数据口径。
- 固定原待估参数、增删相位/基线等辅助模型、改变物理机制、引入外部先验，或改变合同外的样本/波段、参数边界、判定标准，须携最小证据返回建模手，更新原合同与术语表，再复验受影响的 M1/P1/P2。
- 经预定规则从候选方案中选择不算静默改合同；事后改变规则则记录理由并重新安排有效验证。修订只重跑受影响门禁，不无条件重做整个流程。
- 缺少独立观测、必要标定或用户选择时，说明缺失信息及其影响。新增采样、外部协调或超出用户允许范围的行动需另获授权；不得用算法替代不存在的信息。
