# 数值极值、首次事件与全过程约束

仅在结论依赖连续域最大/最小值、首次事件、全过程可行性或据此给出的精度时加载。普通数据汇总、闭式计算及不涉及这些主张的任务不执行本页流程。不要求新增模型、外部检索、固定数量实验或额外 Subagent。

## 1. M1：先定义要验证的主张

在现有模型合同中说明：计算量与单位；优化变量或事件变量；有限/无限搜索域；端点与已知分段点；约束及接触是否算事件；拟输出的结论类型与精度；验证方法、失败条件及处置。辅助指标一旦用于报告精确极值或支持结论，同样适用；不要求登记每个临时变量。

区分三种证据强度：

- **可行候选/已检查点结果**：只说明候选满足已核验的条件，不能据此声称全程可行或全域最优。
- **数值搜索结果**：说明搜索范围、覆盖策略、局部细化和稳定性检查，报告已找到的极值及数值证据，承认未获全局证明。
- **有界或解析证明**：给出实际成立的单调性/凸性推导、误差界、区间包围或全局界，说明其覆盖域；有这些证据才作相应严格主张。

“全过程无碰撞”和“全过程最小裕量为某个六位小数”分别验收。一个局部值为正不能证明其他位置为正；找到更低但仍为正的极小值会否定旧极值，却不自动否定已有充分数值证据支持的无碰撞判断。

## 2. P1/P2：搜索与局部求解分开检查

### 连续域极值

先判断函数是否有可利用的单调、凸或单峰结构。没有依据时，不得只细化一个采样最优点就报告全域极值。对一维扫描，比较已定位的各局部极值候选与端点；有已知分段点或模型切换时，按定义检查接点及必要的单侧值。其他维数采用与其结构匹配的搜索或界限方法，不机械套用一维网格。

网格搜索应记录候选生成方式和覆盖范围。按风险选用步长细化、错位采样、结构引导加密、导数/误差界或独立方法检查遗漏；优先细化可能改变结论的区域。任意有限网格都可能漏掉足够窄的峰谷，细化全部**已检测候选**不等于证明全部真实极值已覆盖。两个嵌套网格结果相同也可能共同遗漏同一区域，不得仅据此声称全局性。

记录局部求解器状态、残差或适用的最优性条件及可行性。成功收敛、很小的局部容差、重复运行一致均不能替代搜索域覆盖；`xatol` 等参数也不自动给出目标函数值误差界。

### 首次事件与全过程约束

求出一个过零点只能证明该处存在事件，不能自动证明它最早。检查之前的区间是否可能发生短暂越界、相切而不变号、接缝跳变或多个根；利用模型结构、局部极值、事件函数或有界细分取得与主张匹配的证据。没有相应证明时，把结果写为有明确覆盖方法的数值首次事件，不把扫描中第一次遇到等同于严格首次。

无限域截断须记录截断范围及远端依据。有限个远端样本、渐近极限本身，不能排除两者之间仍有更大极值；缺少全域界时保留数值范围限制，不强求每道题形式化证明。

### 精度与失败处理

验证阈值依据单位、条件性、结论用途和报告精度设定，不使用统一步长或统一有效位数。检查细化是否改变极值大小、位置、活动约束或可行性；区分局部容差、经验稳定性与可证明误差界。舍入后用于严格约束的数值应重新代入检查，不能把向约束外舍入的近似数当可行参数。

超出预定容差时，扩大候选、加密或改用适当方法；证据仍不足则收缩主张/精度并如实说明。涉及题目要求的主要目标未满足时报告受限结果，不以改写措辞冒充完成。已知错误必须修复，或删除不再需要且不影响任务完整性的错误辅助主张；不能仅补一句“数值近似”后保留错误结论。资源不足可以限制计算，但由全局转局部、全量转抽样时必须同步改变结果含义并重新验收。

## 3. 正式复现与 P2 独立验收

把决定结论的覆盖检查、残差/可行性检查及精度比较并入正式复现入口，或由该入口调用的验证命令。保存适用的变量域、候选极值位置与数值、网格/算法设置、求解状态、失败阈值和检查结果到现有 results/复现记录中。无需强制新增一套固定表格。

检查域涉及关键量词或时序解释时，回到[模型合同](roles/建模手/references/前置合同.md#关键逻辑检查)独立确认其含义；共享作者的区间、端点或事件候选列表不构成覆盖证据。对覆盖不足的判定须影响相关精度或全过程结论，不只增加一项提示。

失败应产生明确非通过状态或非零退出码，并阻止受影响结果以验收通过的身份导出；诊断数据可保留。不能只记录一个差值却不执行阈值判定，也不能只改结果表而不修复生成逻辑。修复后重建受影响的摘要、图表、清单和打包文件并复验；与修复无关的已验证部分不必全部重跑。

P2 回执分开说明：

1. **复现证据**：原命令、输入、代码版本与输出一致性。
2. **独立验证证据**：针对决定结论的风险，采用何种不同推导、候选构造、解析特例、反例或独立实现；检查了哪些对象与区间，仍共享哪些假设。

重跑同一程序仍有复现价值，但不得把它单独称为独立正确性验证。不要为了“独立”强制全部算法重写、所有任务双语言实现或每个数值新增 Agent；围绕最可能影响主张的步骤选取有区分力的检查。验证某个位置的几何函数正确，不等于验证寻找极值的搜索过程正确。

已报告的辅助极值同样纳入主张—证据检查，不能因主答案未变而放行已知错误。回执绑定具体主张和版本，区分“主要答案可保留”与“辅助字段仍需修复”；未覆盖项如实列出，既有 PASS 不得覆盖新发现。

## 4. 维护本规则时的行为验证

有实质修改时，可在隔离工作区用少量结构不同的原始案例进行前向评估，例如多峰目标、边界最优或短时事件。向质检者提供任务、函数/数据和必要规则，不预告预期答案或缺陷位置；观察其实际推导、计算与结论边界，而非只匹配关键词。案例按已暴露风险选择，不要求每个普通建模任务运行整套反例，也不将某届赛题答案写入通用规则。
